StudyRoom

flagship · live ↗

A virtual co-studying platform built to hold real-time video, chat, and study tools in one place.

StudyRoom brings together WebRTC video calling, community chat, a shared-music bot ("Chip"), a game sandbox, and collaborative notes — the ambition is a single platform that covers what people currently split across Zoom, Discord, and separate study tools.

  • Full product documentation: PRD, technical architecture, data models, and socket specs written before implementation
  • Real-time systems: WebRTC signaling, live chat, shared media state

EduTrack

live ↗ · ~1,000 users

Coaching-institute management app used by a real client, with AI-assisted test creation.

Built on Next.js and Supabase for a coaching institute client, EduTrack handles batches, exams, and results — including AI-generated question sets and PDF result reports. Currently gathering live feedback from teachers using it day to day and iterating on the payment and content-locking model.

  • Next.js 16 App Router, React 19, Supabase auth
  • AI-powered exam generation, exam key/PIN access flow

Packet Analyzer

security · under construction

A C++ deep packet inspection tool extended with live threat detection.

Forked and extended from an open-source DPI packet analyzer, with two original additions: a live threat and privacy blocker (tracker detection, plaintext HTTP flagging, TLS certificate validation, malicious domain matching) and an ARP spoofing detector for local network protection. Not yet published — no live demo or public repo link yet.

  • C++, low-level networking, iptables-based blocking
  • Positioned as a systems/security counterpart to the mobile work above
